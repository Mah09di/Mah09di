## 🧠 Detection Mindset

```spl
index=auth sourcetype=linux_secure "Failed password"
| stats count AS attempts, dc(user) AS users BY src_ip
| where attempts > 10
| sort - attempts
```

> *Example: brute-force detection logic. Detect the pattern, validate the alert, escalate with context.*

| Severity | Meaning | Action |
|:--:|:--|:--|
| 🔴 **Critical** | Confirmed compromise | Contain immediately, escalate |
| 🟠 **High** | Likely malicious activity | Investigate, enrich, escalate |
| 🟡 **Medium** | Suspicious, needs validation | Triage and correlate |
| 🟢 **Low** | Informational / benign | Tune and document |
